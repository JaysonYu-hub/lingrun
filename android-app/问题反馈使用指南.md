# 问题反馈 · 0.4.4-beta.1

本版本保留全部本地模拟测试、自定义间隔、真实监测和原有 JSON 导出功能。

## 维护者先准备

在线反馈需要维护者另行提供 HTTPS 接收地址与测试提交码。本仓库不提供接收服务源码，也没有预置已上线服务器。没有接收地址时，App 可以填写和保存反馈，但不能完成网络提交；可使用导出报告功能自行联系维护者。

## 用户提交问题

1. 进入底部“测试与报告”→“反馈服务器设置”，填写维护者给出的完整 HTTPS 地址和测试提交码并保存。这个码不是学校密码。
2. 问题出现后，点监测首页“遇到问题？填写反馈”，或“测试与报告”→“填写问题反馈”。
3. 选择“本次报告”或“最近保存的报告”。无法登录、没有运行记录时，选择“不附报告”也能反馈。
4. 写清操作步骤、问题现象、预期结果，例如：“晚操监测开始后锁屏 5 分钟，距离更新但没有语音，回到 App 才播报；希望锁屏时直接播报。”请勿填写密码或验证码。
5. 点“保存并准备提交”，核对接收地址、问题文字和是否附加测试 JSON，再点“提交”。只有这一步会上传。反馈不会停止正在进行的后台监测，附加的是创建时的报告快照。
6. 显示“提交成功，服务器已收到”和反馈编号才算已确认。可到“反馈记录”再次查看回执。维护者按编号找到你的文字及 JSON。

## 没提交成功怎么办

- 没配置地址：反馈已保存在本机，配置后进入“反馈记录”点击该记录再提交。
- 401/403：向维护者核对提交码，不需要重新登录学校。
- 网络/回执失败：联网后重试原记录，不必重新填写；同一编号不会重复保存。上传期间尽量留在 App，系统终止上传不会丢失已保存的待提交记录。
- 换了服务器地址：旧反馈保留旧地址，需恢复原地址及对应码后重试；不会自动把旧报告转发到新地址。
- 没有服务器：仍可用原有“导出本次 JSON 报告”或“导出最近一次保存的报告”，自行发送给维护者。

填写的草稿和反馈保存在应用私有目录；卸载或清除数据会丢失。报告包含设备、版本、查询和播报诊断，不上传学校私有会话。维护者只应将反馈用于问题排查。当前没有 App 内客服回复、服务器收件列表或自动发到 Codex 对话的功能。
