# 更新记录

## 0.4.3-beta.1 · 2026-10-05

- 增加问题反馈表单，可附本次诊断快照、最近保存报告，或无附件反馈登录问题；快照不停止后台监测。
- 手动配置 HTTPS 接收地址和测试提交码，保存草稿及待提交记录，确认目标地址后主动上传；匹配服务器回执后才显示已收到。失败可重试，服务端按反馈编号去重。
- 增加独立 Node.js 小规模内测接收服务，带提交码校验、请求大小/频率/存储数量限制、原子文件保存，不提供公开下载接口。服务尚未部署。
- 保留本地模拟、自定义测试间隔、真实监测和 JSON 导出。后台线程上传不依赖无障碍或学校登录凭据；不承诺 App 被终止后继续上传。
- 增加反馈协议、部署及手机操作说明。公网 HTTPS 与 Android/鸿蒙手机上的提交操作仍待部署后验收。

## 0.4.2-beta.1 · 2026-10-02

- 新增通用 Android 后台运行准备：首次启动实跑/后台检查/模拟时检查通知、电池优化豁免、系统后台限制。
- 用户点击“系统授权”后，先申请Android13及以上通知权限，再打开本应用电池优化豁免确认。增加REQUEST_IGNORE_BATTERY_OPTIMIZATIONS声明，仅用于请求，不会在安装时自动加入白名单。
- 返回后查询真实授权状态，不把打开系统设置当成已授权；已具备通用设置的设备跳过提示，拒绝后可继续且不反复弹窗。
- 原生系统入口不可用时回退到电池优化列表或应用详情。厂商额外限制仍需核对，未宣称通用系统接口可自动修改所有品牌设置。
- 用户反馈0.4.1在本机手动设置后后台播报正常；本次改进授权引导，保留模拟、正式监测和JSON导出。授权路由主机检查与构建通过，系统弹窗仍待各机型验收。

## 0.4.1-beta.1 · 2026-10-02

- 模拟平台新增“自定义更新间隔与测试时长”，默认20秒/120秒，允许5—600秒间隔与30—7200秒时长，时长至少为间隔两倍。
- 设置在本机记忆、写入模拟报告，仅对新建模拟生效；重接入沿用同一模拟记录，固定5分钟/20分钟场景仍保留。
- 模拟轮询间隔不超过设置的发布间隔（最短5秒）；真实学校接口查询策略不变。
- 可选保留第90—120秒规则中断，勾选时至少测试150秒。短间隔语音可能合并中间提示，UI明确说明。
- 回归覆盖自定义边界、精确发布时间、去重、结束距离与实际服务短间隔处理。未连接手机验收。

## 0.4.0-beta.1 · 2026-10-02

- 修复规则接口暂不提供详情被误判为跑步结束。保留最近距离、隐藏旧倒计时、每15秒重试；持续5分钟仍不可用则单独标记 DATA_UNAVAILABLE，不冒充跑步结束。
- 原生服务使用独立 HandlerThread 调度查询、打卡判断、语音请求和传感器回调；切后台不再触碰 Activity 的语音客户端。
- 增加导航语音音频属性、瞬时音频焦点与媒体播放前台服务类型。记录语音请求/开始/结束的前后台、屏幕、音量、焦点和时钟。语音出错不再终止查询。
- 短暂网络故障最多退避重试3次；明确授权过期停止并由用户处理。未绕过系统省电策略。
- 大字显示平台路程；主界面、业务播报与服务报告的圈数按累计距离除以400米；预测仍使用新打卡间隔，不能用估算替代官方距离。
- 新增本机模拟平台：初始2800米、每分钟增加200米、5分钟含规则中断、20分钟熄屏、手动发布、重新接入同一记录。无网络请求或学校成绩写入。
- 停止服务后等待报告保存再导出，保留全部诊断入口。报告schema4，模拟报告明确标记simulated。
- 电脑回归/编译/同签名检查通过；后台触发声音与长时间熄屏仍待用户真机验收。

- 仅前台运行，切后台、离开网页、查询/语音错误时停止。
- 已完成源码编译、签名校验与离线逻辑检查。尚未真机安装或实跑，不标记为稳定版。

### 已知限制

- 首次在原生 App WebView 中的登录与接口查询需要重新验收；AutoJs6 成功不等于 App 已实机通过。
- 原 R3 的实际业务语音听感未通过，原生 TTS 路线也需手机试听及结果听感确认。
- R4 的真实点位身份、时间格式、位置精度、步频及实跑圈数尚未实测。
- 无后台/锁屏监测；无云端多人控制台或自动更新服务器。
- Android 8 起可安装；网页脚本依赖较新的系统 WebView。旧 WebView 出现兼容错误时需要先升级系统 WebView。
- 报告保留最近 500 条事件；导出不含登录凭据、原始读卡器ID或经纬度，仍包含运动摘要。
