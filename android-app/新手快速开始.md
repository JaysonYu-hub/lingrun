# 第一次使用：登录 → 健身长跑 → 返回监测 → 开始

适用于跑点助手 **0.4.3-beta.1** 及其引导界面。直接覆盖安装新版，不要先卸载。

## 第一步：在 App 内登录学校

打开跑点助手，点 **“登录 / 查看学校网页”**。按网页提示完成学校账号和 VPN 登录。

登录成功后看到“体育与健康校园”首页，还没有完成全部准备步骤。继续第二步。

## 第二步：点击“健身长跑”

在学校平台首页找到 **“健身长跑”** 并点击。不要选“跑步记录”“运动生涯”或其他项目。

正确页面通常能看到：

- 顶部标题“健身长跑”；
- 早操、晚操考勤区域；
- 跑操距离、锻炼时长、跑操时间等内容。

未开始运动时显示“未起跑”“无”或暂无记录是正常的，不用等有跑步数据再返回 App。

新版网页上方会提示：**“已到健身长跑。点‘返回监测’，再点‘开始监测’。”**

## 第三步：点 App 的“返回监测”

点学校网页上方绿色的 **“返回监测”** 按钮，也可以点 App 底部的 **“监测”**。

这个操作只切换 App 页面，会保留刚才打开的学校网页；无需退出账号，也无需关闭 App。此时会回到显示圈数、路程和“开始监测”按钮的界面。

新版中，在学校网页内按手机返回键或使用返回手势，也会先回到监测页。

| 操作 | 用途 |
|---|---|
| App 上方“返回监测”或底部“监测” | 回到跑点助手，准备开始监测 |
| App 上方“网页后退” | 退回学校网页的上一页，例如从选错的项目返回首页 |
| 学校网页里的“退出登录” | 退出学校账号，平时返回监测不要点它 |
| 手机 Home 键/返回桌面 | 离开 App 界面；不是“返回监测” |

## 第四步：选择早晚操并开始

1. 选择本次对应的“早操”或“晚操”。
2. 点击 **“开始监测”**。
3. 完成中文试听确认，等待出现“监测中”和下一次更新时间。
4. 然后按正常方式运动。新增打卡会按原逻辑提示；没有变化时可以没有声音。
5. 如需切后台或熄屏，应先完成启动和试听，确认已经监测中。首次使用新手机，建议先在“测试与报告”做90秒后台检查。

## 如果点开始又回到了学校网页

通常需要补完第二步。登录成功不等于已经进入“健身长跑”：先点击该项目，等页面加载完，再点 App 上方“返回监测”。如果学校明确提示登录过期，则按提示重新登录。

## 想再看指南或反馈问题

- 主界面顶部点 **“首次使用？查看操作指南”**，可以随时重看。
- “测试与报告”中也有 **“使用指南 · 登录与返回监测”**。
- 0.4.3 可点首页 **“遇到问题？填写反馈”**，选择报告并填写文字，再确认提交到维护者提供的服务器。首次先在“测试与报告 → 反馈服务器设置”配置地址与提交码；未部署服务器时可先保存待提交记录。详见《问题反馈使用指南》。
- 遇到问题，到“测试与报告”点“导出本次 JSON 报告”。导出会先停止当前监测。反馈操作步骤、手机型号和 JSON 即可，不要发送密码、验证码或登录凭据。

新版本的返回逻辑已完成电脑端回归与编译检查；不同机型的按钮排版和系统返回手势仍需在手机上确认。

## 首次后台授权（0.4.2新增）

首次开始监测或模拟时，应用会检查后台设置。若显示“后台运行准备”，点“系统授权”，在系统窗口选择允许。返回后核对通知已开启、电池优化已豁免，再点“继续开始”。已设置好的设备自动跳过。

用户仍可拒绝并继续，之后不反复弹窗；需要补设时到主界面“后台运行设置 · 系统授权”。厂商额外的后台启动管理无法由通用接口自动授予，可通过“应用设置”核对。授权流程使用标准Android接口，不限华为；各品牌实际弹窗仍需测试。
