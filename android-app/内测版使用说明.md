# 跑点助手 0.4.3-beta.1 内测版

本版针对10月2日报告修复详情暂不可用误判结束，调整后台调度与音频，并新增原地模拟平台。属于专项内测版；电脑回归不等于手机后台声音和长时间熄屏已通过。先阅读《原地模拟测试指南》。

## 安装更新

直接安装 `trackcheck-0.4.3-beta.1.apk` 覆盖旧版，不要先卸载。包名和签名保持一致，已有本地报告和登录数据按系统覆盖安装机制保留。学校会话本身仍可能过期，过期后在应用内重新登录。

## 日常使用

1. 点击“登录 / 查看学校网页”，完成学校/VPN登录后，还要点击学校首页的“健身长跑”（不是“跑步记录”）。看到早操/晚操考勤与跑操距离后，点 App 网页上方绿色“返回监测”；不要退出登录或关闭 App。详细步骤见 [新手快速开始](新手快速开始.md)。
2. 返回“监测”，选择早操或晚操，点击“开始监测”。完成语音确认，等监测开始后即可按原方式使用后台运行。
3. 跑步页大字显示学校累计路程，并显示由距离折算的圈数和累计用时、下个点剩余时间、最近提示。下一次更新时间显示在顶部。
4. 圈数按学校累计距离 ÷ 400米计算，例如2800米为7圈；中途接入和重新开始后以最新距离恢复。剩余时间是最近一次学校查询值，不伪造持续变化的计时。
5. 新打卡或相关状态变化时按原逻辑提示；数据没变时保持静默。需要时点击“重播提示”。
6. 完成后点“停止监测”，或从常驻通知停止。停止后保留本轮路程和圈数，剩余时间显示“—”；再次开始时清空上一轮展示。

## 定位和步频

在“测试与报告”→“定位与步频辅助”中开启或关闭。默认可不开启；未授权或没有传感器数据时仍按打卡间隔估算。该区域可以查看详细采样状态，主跑步页不显示采样数。

## 保留的测试入口

底部“测试与报告”保留：离线模拟、单次接口诊断、五轮自动验收、90秒后台与熄屏检查、语音试听、传感器诊断、刷新学校页与会话、应用后台/电池设置、实际听感标记。

这里的测试入口是应用内工具，没有对外开放网络调试端口。每位测试者独立登录，报告不会自动上传。

后台次数、熄屏/非交互次数、锁定查询、休眠事件等汇总移到此页。查询时刻、屏幕状态、计时延迟、传感器采样、打卡判断、语音状态、结束原因等仍记录在完整 JSON 中；主界面不展示不等于没有记录。

## 导出反馈

0.4.3 新增“填写问题反馈”：可将问题文字与测试 JSON 一起提交到维护者的 HTTPS 服务器。先在“反馈服务器设置”填写维护者提供的地址与提交码；服务器尚需部署。提交前会显示目标地址供确认，失败保留待提交记录。此入口附加当前快照，不停止后台监测。详见同包《问题反馈使用指南》。原有手动导出仍可使用：

1. 到“测试与报告”，按实际听感选择“最近业务播报听到了 / 没听到”。
2. 点“导出本次 JSON 报告”，选择保存位置。若任务仍运行，导出会先停止监测。
3. 重新打开应用后，可用“导出最近一次保存的报告”取得上一轮记录。建议每轮测试后及时导出。
4. 反馈版本、手机型号、问题发生时间和操作步骤，并附 JSON。无需提供密码、验证码、Cookie、Token 或完整网络抓包。

报告保留原有字段与事件容量：前台分项最近500条事件，服务监测最近1000条事件；并非无限历史记录。记录含运动摘要和设备信息，不含登录凭据、原始读卡器编号或经纬度。

本版完成编译、回归与同签名检查；新的页面排版仍需在测试手机上确认。遇到问题可继续使用保留的测试入口定位，不需要重新换回 AutoJs6。
